# YouTube Downloader — Online

Веб-версия интерфейса Windows-приложения. Windows-специфичные функции удалены: нет автозапуска, системного трея, выбора локальной папки, Windows-уведомлений и встроенного обновления yt-dlp.

## Что есть
- современный интерфейс в том же стиле;
- вставка ссылки;
- получение превью;
- 360p / 480p / 720p / 1080p / 1440p / 2160p;
- видео MP4 с объединением video+audio через FFmpeg;
- MP3;
- реальный прогресс, скорость и ETA;
- автоматическая загрузка готового файла в браузер.

## Сервер
На сервере должны быть установлены `yt-dlp` и `ffmpeg` и доступны через PATH.

Установка:
```bash
python -m pip install -r requirements.txt
```

Запуск:
```bash
uvicorn server:app --host 0.0.0.0 --port 8000
```

Открыть:
`http://SERVER_IP:8000`

Для публичного сайта рекомендуется поставить Nginx/Caddy перед Uvicorn, HTTPS, лимиты размера/частоты запросов, очередь задач и автоматическое удаление временных файлов.

Используйте сервис только для контента, который разрешено скачивать и обрабатывать.
